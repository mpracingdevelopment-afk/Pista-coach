# Pista Coach V1

MVP browser da aplicação de coaching/análise em pista.

## Incluído
- Dashboard
- Pilotos
- Pistas
- Sessões
- Layout de Portimão como exemplo
- Curvas clicáveis
- Análise estruturada por curva: travagem, entrada, apex, saída, erro/correção, comentário e classificação
- Score simples da sessão
- Histórico
- Persistência local no browser
- Interface responsiva

## Nota
Esta versão é deliberadamente um MVP local. O próximo passo é substituir os layouts de exemplo pelos layouts reais e migrar os dados para uma base de dados online com autenticação.
